# Monthly Daymark Review

Run on the last day of each month using the user's own Codex automation.

1. Read the user's weekly reports for the month, plus the latest Daymark export if available.
2. Summarize repeated goals, completed outcomes, active-day consistency, and unfinished carryovers.
3. Separate facts from inferences.
4. Send the review through the user's own configured email connector.
5. Recommend deletion of superseded raw exports only after the user confirms the monthly report is correct.

## Review format

**Month:** [month and year]

**Outcomes**
- [meaningful result]

**Consistency**
- [active days and week-over-week pattern]

**Recurring themes**
- [theme supported by multiple entries]

**Friction**
- [repeated carryover or gap]

**Next month**
- [one focus]
- [one habit adjustment]
